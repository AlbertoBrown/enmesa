Mapeo Semántico

¿Qué es el Mapeo Semántico?

El mapeo semántico es una técnica de procesamiento de lenguaje natural (NLP) que permite traducir el lenguaje coloquial del usuario a datos estructurados del sistema.

En lugar de que el cliente diga exactamente "2x Victoria — Caña (Barril · 20 cl)", puede decir "ponme dos cañitas frías" y el sistema entiende qué producto y cantidad quiere.

Flujo del Mapeo

Entrada del Usuario
"ponme dos cañitas frías"
Tokenización
["dos", "cañitas", "frias"]
Búsqueda Semántica
cañitas → caña, dos → 2
Producto Mapeado
2x Victoria — Caña = 4,00€

Cómo Funciona

1

Estructura del Menú

Cada producto tiene múltiples keywords y sinónimos asociados:

{
  id: "cerveza-cana",
  nombre: "Victoria — Caña",
  precio: 2.00,
  categoria: "bebidas",
  keywords: [
    "caña", "cerveza", "victoria"
  ],
  sinonimos: [
    "cañita", "cañitas", "birra",
    "rubia", "cervecita"
  ],
  modificadores: [
    "fría", "frías", "fresquita"
  ]
}
2

Normalización del Texto

El texto del usuario se normaliza para facilitar la búsqueda:

// Entrada original
"ponme dos cañitas frías"

// Después de normalizar:
→ Minúsculas: "ponme dos cañitas frías"
→ Sin tildes: "ponme dos canitas frias"
→ Tokens: ["dos", "canitas", "frias"]
→ Cantidad: "dos" → 2
3

Sistema de Puntuación

Cada coincidencia recibe una puntuación según su relevancia:

// Pesos de puntuación
const SCORES = {
  nombre_exacto:    100,
  keyword_exacto:    80, // "caña"
  sinonimo:          60, // "cañitas"
  categoria:         40, // "bebida"
  parcial:           25,
  modificador:       15  // "frías"
}
4

Selección del Mejor Match

Se selecciona el producto con mayor puntuación:

// Query: "ponme dos cañitas frías"
